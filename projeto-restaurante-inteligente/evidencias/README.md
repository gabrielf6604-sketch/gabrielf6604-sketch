# Evidências da solução

A avaliação permite no máximo **5 capturas de tela**. Adicione somente imagens reais do protótipo em execução, sem dados pessoais ou informações sensíveis.

Sugestão de seleção:

1. Tela inicial / visão geral.
2. Mapa de mesas com estados diferentes.
3. Alteração de estado de uma mesa.
4. Endpoint/API ou fluxo de pedido, quando implementado.
5. Painel de indicadores, quando implementado.

Não crie capturas para módulos que ainda não funcionam. Se o protótipo atual demonstrar somente o mapa de mesas, use apenas as imagens correspondentes e deixe os demais itens como etapas futuras.

Formato recomendado: PNG ou JPG, com nomes `01-visao-geral.png` até `05-painel.png`.

As imagens ainda não foram adicionadas. Após inserir os arquivos, atualize o README principal para exibi-los.
